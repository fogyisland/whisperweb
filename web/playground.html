§ 沙盘

上传音频，让服务器跑一遍 Whisper。

选一段样本（或上传自己的音频），挑模型与参数，点运行。Node 端会调起 Python whisper_runner.py，把进度用 SSE 一段段推回来，再把最终转写渲染在右侧。点击转写行，音频跳到那一秒。

1. 音频

支持 mp3 / wav / flac / m4a / ogg。文件发到本机 Node 服务，不会外传。
选个样本或上传文件后这里画波形。

    沙盘做了什么

    点击「运行」后，浏览器把音频文件 POST 到 /api/transcribe。Node 服务 spawn 出 Python 子进程跑 whisper_runner.py。Python 把每一行进度以 JSON 写到 stdout，Node 实时转成 SSE 推回浏览器。终端字幕逐条出现，最后一段是完整结果。

    CPU 上 large-v3 一分钟音频约几分钟。tiny 模型实时性最好。GPU 会快很多。
